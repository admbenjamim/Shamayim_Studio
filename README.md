# Shamayim Studio

Site do Shamayim Studio — estúdio criativo cinematográfico para edição de vídeo premium, design gráfico e identidade visual.

## Rodar localmente

**Pré-requisitos:** Node.js

1. Instalar as dependências:
   `npm install`
2. Configurar a `GEMINI_API_KEY` no arquivo `.env.local` com sua chave da API Gemini
3. Rodar o app:
   `npm run dev`
